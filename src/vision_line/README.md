## 2026年3月29日 - v1.0

初步完成了弯道巡线：

## 2026年4月1日 - v2.0

## 2026年4月11日 - v2.1

1. 完成识别拐点：取2个相邻像素点作为一个点蔟，相邻3点蔟之间的夹角，如果夹角在一定范围内判定为拐点

2. 修复了变量错误复用导致左右巡线逻辑相互影响的问题


## 2026年4月15日 - v2.5

1. 完成识别拐点，对于找不到三岔路口的水平停止线，选择的策略是用右侧拐点上面的线去补左侧的线（如果右转的话）

    但是上机测试了一下,补线的策略应该不行，至少是在没有透视变换转鸟瞰图的情况下

1. 新增状态机：

   1. 无任务模式
   2. 接收到信号后进入巡线模式，这里用一个参数模拟信号
   3. 巡线指定时间后开始寻找拐点，等待的目的是让小车进入直道，防止一开始把其他点错认为是拐点
   4. 两个拐点都落在图像下方时，此时已经到达三岔路口，停止搜索拐点，开始搜索水平白线
   5. 当水平白线中点落在图像下方时，此时准备转弯，停止搜索白色停止线

    后面还有状态，不过暂时就到这里

## 2026年4月18日 -v3.0


***重大更新！！***

1. 使用 `np.diff()` 在一行内搜索像素跳变点，删去了原先的内层循环

2. 使用横向形态学将水平停止线和斜线分割，并使用 `find_contours()` 完成连通域搜索

        通过以上2个关键性改动，图像处理效率提升显著

3. 先对原图使用大尺寸高斯模糊得到背景光照分布，再用原图去减，得到滤除光照背景后的特征图，用这种方法可以有效的抑制光照干扰
